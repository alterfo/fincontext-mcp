# FinContext MCP

Нейтральный, self-hosted, open-core **MCP-сервер финансового контекста для РФ SMB**: подключает AI-агента разом ко всем банкам и учётной системе бизнеса и отвечает на живые вопросы (реальный кэш по всем счетам, «прошёл ли платёж», прогноз кассового разрыва, сверка выписка↔учёт).

- **Доверие by design:** клиент разворачивает сервер у себя (Terraform → его Yandex Cloud), токены банков/учёта (read-only) лежат в его Lockbox и к разработчику не уходят.
- **Стек:** Yandex Cloud Functions + API Gateway + YDB + Lockbox; JS.
- **Монетизация:** open-core (открытое ядро + коннекторы Точка/МойСклад), Pro-лицензия разблокирует движок сверки/прогноз/1С-Контур/алерты; оплата через YooKassa.
